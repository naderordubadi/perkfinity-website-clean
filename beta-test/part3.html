Part 3: Campaign Creation

Build and dispatch promotions using the Merchant Dashboard

🔒

Phase A: Dashboard Login & Profile

Log in and verify profile updates.

A1
Sign In to the Merchant Dashboard
  1. Go to perkfinity.net on your computer.
  2. Click Merchant Sign Up / Sign In in the top navigation bar.
  3. On the sign-in page, click Sign in here at the bottom.
  4. Enter the email and password you created in Part 1 and click Sign In.
💡 Tip: If you can't remember your credentials, they're the same ones you wrote down at the end of Part 1 Step 3.
A2
Update Profile & Replace Logo
  1. Navigate to the Profile tab at the top.
  2. Update a few fields (e.g. Website, Suite / Unit #, Phone Number).
  3. Click the Replace Logo button. Select a new image file from your computer (PNG/JPG).
  4. Scroll down, enter your Current Password, and click Save Changes.
⚠️ Check: After saving, verify that the new logo immediately updates in the top header and stays persistent if you refresh the page.
📣

Phase B: Campaign Creation

Build and dispatch 3 promotions and 1 announcement.

💡 How Perkfinity Delivers Campaigns — Smart Daily Digest

When you send a campaign with Email + Push delivery, Perkfinity uses a Smart Daily Digest approach rather than sending each campaign instantly. All promotions and announcements sent to members are batched together and delivered once each morning — keeping inboxes clean and avoiding notification fatigue.

However, the offer is available to your members immediately. As soon as you click 🚀 Send Promotion, the campaign becomes active in the app — members can see and activate it right away from their Home screen, even before the Daily Digest email or push notification arrives.
B1
Create Campaign 1 (All Members)

Navigate to the Create a Promotion tab, and complete the 6-step wizard:

  1. Type: Select Percentage Off.
  2. Details: Enter a discount percentage (e.g., 20%). Set expiration to 3–4 days in the future.
  3. Condition: Select No Minimum.
  4. Delivery: Select Email + Push.
  5. Audience: Select All Members.
  6. Preview & Send: Review the generated email preview on the right, ensure the logo and offer look correct, then click 🚀 Send Promotion.
B2
Create Campaign 2 (Targeted Audience)

Click Start Over to build the next campaign.

  1. Type: Select Dollar Off.
  2. Details: Enter $5 Off. Set expiration to a couple days out.
  3. Condition: Select Minimum Spend and enter an amount (e.g., 20).
  4. Delivery: Select Email.
  5. Audience: Select Redeemed — Last 30 Days.
  6. Review and 🚀 Send Promotion.
B3
Create Campaign 3 (BOGO)

Click Start Over one more time.

  1. Type: Select Buy One Get One.
  2. Details: Fill in the Buy/Get details and item description. Select a future expiry.
  3. Condition: Select Minimum Items and enter the same quantity you set in the Buy field above (e.g. if Buy = 1, enter 1).
  4. Delivery: Select Push.
  5. Audience: Select All Members and hit 🚀 Send Promotion.
B4
Dispatch an Announcement

Announcements don't require redemption—they're just broadcast messages to the member list.

  1. Type: Select Announcement.
  2. Details: Add a Subject (e.g., "We are open late Fridays!") and a Message Body. Leave expiration blank.
  3. Delivery: Select Email + Push.
  4. Audience: Select All Members and 🚀 Send Promotion.
📊

Phase C: Verification & History

Ensure the campaigns saved properly to the backend lists.

C1
Verify Campaign History
  1. Under the Create a Promotion tab, switch to the Campaign History sub-tab.
  2. Verify that all 5 entries appear in the table — the 3 promotions + 1 announcement you just created, plus the Initial Sign-Up Perk that was automatically activated when you completed merchant registration in Part 1.
  3. Check that the Type, Audience, and Expires dates match exactly what you inputted for each campaign.
💡 About the Initial Sign-Up Perk: This is the welcome offer you set during merchant sign-up (e.g. "10% Off First Visit"). It appears as the first entry in Campaign History and is automatically available to any member who scans your QR code for the first time.
C2
Verify Member List Status
  1. Switch to the main Member List tab at the top of the dashboard.
  2. This table logs member activity. Filter by "Status" using the dropdowns.
  3. You should see entries corresponding to your new campaigns with the status "Created" or "Announcement".
📸 Please Record: Taking screenshots of both the Campaign History and the Member List tab (showing the new rows) is extremely helpful for verifying the backend data ingestion!
